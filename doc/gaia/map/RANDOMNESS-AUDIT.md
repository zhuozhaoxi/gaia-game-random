# 盖亚随机地图公平性审计报告

审计日期：2026-09-25  
审计分支：`feature/four-player-expansion-map-generator`  
被测生成器：`js/gaia-map-core.js`（通过 `js/gaia-map-generator.js` 暴露同一接口）

## 结论

当前生成器在 **规则合规性** 上表现稳定，但若“公平”定义为每个合法位置、方向都必须严格等概率，则结论是：**不完全公平**。

- 300,000 张地图均成功生成，合规率 100%，未发现同色行星相邻或舰队距离违规。
- R2 板块位置分布符合已声明规则。01–04 会优先竞争两个中心位，因此它们与 05–10 本来就不可能在十个位置上等概率。
- 三角板的位置、0/120/240 度方向、实心/空心面均符合等概率预期。
- R2 初始方向是等概率，但冲突处理只重新旋转发生冲突的板块，最终方向存在轻微且可复现的偏差；两轮样本中的最大偏差分别为 0.388 和 0.607 个百分点。
- 舰队是在 21 个合法四格组合中等概率选择，因而“合法组合”公平；但各坐标能参与的合法组合数量不同，所以单个坐标出现舰队的概率为 28.571%–47.619%，不是等概率。其他特殊板块会继承这一位置差异。

如果产品目标是“遵守规则、宏观分布接近随机”，当前实现可以接受。如果产品目标是“所有最终合法地图等概率”或“每块板的最终方向严格等概率”，需要更换 R2 旋转采样算法，并重新定义特殊格的位置公平口径。

## 测试方法

- 主测试：200,000 张，固定种子 `20260925`，用于下方完整明细。
- 复测：100,000 张，固定种子 `20260926`，用于确认 R2 方向偏差是否可复现。
- 总生成量：300,000 张地图。
- 总检查量：3,000,000 次 R2 放置、2,400,000 次三角板放置、3,000,000 次特殊格放置。
- 每张地图均调用正式生成器的 `validate()` 检查。
- 审计脚本使用可复现的均匀伪随机数源替换 `Math.random()`；除此之外直接加载正式的板块数据和生成器代码，没有复制生成逻辑。

## 代码审查结果

1. 通用洗牌使用标准 Fisher–Yates，实现本身无明显偏差。
2. R2 位置先等概率抽取 01–04 中的两个中心板，再分别洗牌中心和外围板，符合当前业务规则。
3. R2 方向第一次抽取为 0–5 等概率；后续冲突重转和回溯求解以“尽快找到合法解”为目标，不是均匀合法解采样器。这是当前唯一明确的算法公平性缺口。
4. 三角板使用独立洗牌、二项正反面选择和三项方向选择，逻辑符合等概率要求。
5. 特殊板先枚举全部合法舰队组合，再均匀选择组合并洗牌舰队身份，保证合法组合和舰队身份公平；无法保证每个坐标拥有相同的舰队边际概率。

## 建议

### 保持现状

适用于“只要求规则合规，允许小于约 0.7 个百分点的最终方向差异”。当前稳定性良好，性能也足够。

### 严格公平模式

如果要求最终方向或最终合法地图严格公平，建议：

1. 对固定的 R2 位置排列，使用带计数的回溯或动态规划计算各分支可产生的合法解数量。
2. 按各分支的合法解数量加权选择，而不是找到第一个合法解就返回。
3. 明确特殊板公平口径：是“21 个合法舰队组合等概率”，还是“十个坐标的舰队边际概率尽量相等”。两种定义不同，后者需要对合法组合做非均匀加权。
4. 将本审计脚本加入回归测试，修改随机算法后至少运行 100,000 张，并设置位置、方向和正反面分布容差。
